# Daksh Chhabra — Personal Brand Website

## Vision

Build a premium personal brand website that positions Daksh Chhabra as a Brand Strategist and Creative Director.

The website should feel timeless, minimal, elegant, and intentional—not like a portfolio template.

Inspired by:
- Apple
- Linear
- Stripe
- Pentagram
- Awwwards

---

# Goals

- Showcase selected work through case studies
- Demonstrate strategic thinking, not just execution
- Reflect a premium design aesthetic
- Be fully responsive
- Achieve excellent Lighthouse performance
- Deploy on Vercel
- Use a custom domain (dakshchhabra.com)

---

# Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Vercel

---

# Sections

- Navigation
- Hero
- Selected Work
- Brands
- About
- Philosophy
- Contact
- Footer

---

# Design Principles

- Lots of whitespace
- Large typography
- Minimal color palette
- Smooth, subtle motion
- Every animation should have a purpose
